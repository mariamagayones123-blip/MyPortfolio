# Project Roadmap

**Status:** Active
**Version:** 1.0
**Last Updated:** 2026-08-05
**Related Documents:** [AI Project Instructions](../12_AI/AI_Project_Instructions.md), [README](../../README.md)

## Purpose

This document defines the **single, authoritative, final implementation order** for the
Interactive Developer Portfolio project. Every engineering report, README status line, code
comment, and AI-assisted recommendation must reference this order exactly. See
[AI Project Instructions](../12_AI/AI_Project_Instructions.md) for the compliance rule that
governs how this document is used.

## Scope

Applies to all implementation work on this project, regardless of who or what (human or AI
assistant) performs it. Does not cover day-to-day bug fixes or documentation-only corrections
(such as this roadmap review), which may happen at any time without being tied to a phase.
